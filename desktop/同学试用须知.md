# Shark · 试用说明

Shark 在你的电脑上运行。云盘抓链使用你在浏览器中已登录的迅雷或百度网盘，导出的片段保存在你选择的文件夹。

## Mac

解压完整 ZIP，打开「Shark-mac-arm64.app」。Mac 包适用于 Apple Silicon（M 系列），系统下限声明为 macOS 13.5，实际兼容性以目标设备验收为准。包内含 Node.js、FFmpeg 和 ffprobe。默认素材目录为「影片/片段取材」，可在面板选择其他目录。

当前是使用临时签名的本地试用包，尚未经过 Apple Developer ID 签名与公证，因此系统可能阻止打开。不要关闭系统安全保护；计划公开分发时会补齐签名、公证及独立机器验收。

关闭应用会停止本机服务与正在取材的任务。再次启动后可用原有书签重新抓取片源。已完成的片段保存在你选择的素材目录。

## Windows

Windows 包面向 x64。完整解压后打开「Shark.exe」或「启动片段取材.cmd」，面板会在 Microsoft Edge 打开。取材期间保持终端窗口运行。随包包含 Node、FFmpeg 和 ffprobe。最新版仍待 Windows 真机验收。

默认保存位置是用户目录下的 `Videos/片段取材`，它可能与 OneDrive 或系统重定向后的「视频」目录不同。首次使用请点「选择文件夹」指定你实际要用的位置，再检查是否可写。当前尚未完成重定向目录的 Windows 实测。

MKV 能否播放取决于播放器是否支持它所含的视频和音频编码；Windows 的系统浏览器不保证能预览每一种 MKV。可使用支持对应编码的本地播放器；是否能导入剪映也要以实际文件为准。可选 MP4 工作副本不会把 HEVC 等视频自动改成 H.264。

## 首次使用

1. 选择保存文件夹，点击「使用示例视频」验证本地出片。
2. 使用云盘时，在「浏览器抓链」打开安装页，将书签拖进 Mac 的 Chrome 或 Windows 的 Edge 书签栏。
3. 在同一浏览器登录迅雷或百度网盘。点抓链书签，再从网盘中触发目标影片的读取。回到 Shark 核对片源。如需使用已配置的 CloudDrive2，在「我的云盘」连接其 WebDAV。
4. 填写一个或多个片段的时间范围、前后余量和字幕选项，加入顺序队列。取材完成后可从记录打开保存文件夹。

迅雷已有早期版本的真实取片记录。当前预览的真实网盘出片需要按账号、设备和片源验收。远程取材先验证范围读取能力，并按界面设置限制接收数据量。

原码 MKV 主本复制视频数据，不重新压缩；可选 MP4 工作副本保留视频编码并将所选音频转为 AAC 双声道。MP4 并不保证所有视频编码都能在当前剪映版本导入。HDR/杜比视界没有额外做色调映射，需实际核对剪辑软件效果。

本工具显示自己接收的流量。CloudDrive2 或网盘上游的预取、缓存、下载流量不在这个统计里，不能据此推断上游只读取了同样大小的片段。

## 数据与开源许可

密码只用于当前本机进程连接，不写入启动脚本或分发包。日志和任务清单不应包含密码、访问令牌或完整带签名的链接。导出片段、任务记录、个人设置位于你的本地用户目录；分发包不含开发者测试电影。

第三方许可证在 Mac 应用的 `Contents/Resources/Licenses` 或 Windows 包的 `Licenses` 中。FFmpeg 的同版本完整源码、许可证和构建参数随包提供，可自行重建或替换 `app/bin/ffmpeg`、`ffprobe`。修改 Mac 应用后原有签名会失效，需要自行重新签名。

当前版本不提供自动更新。只从你信任的分发者取得更新包并核对 SHA256；已有素材不需要随应用更新移动。
