# Shark · Windows x64 + Edge + 迅雷与百度

1. 把 ZIP 完整解压到本机文件夹，双击带鲨鱼鳍图标的 `Shark.exe`。工具会在 Microsoft Edge 打开本机面板。取材时请保留启动窗口，也可通过「启动片段取材.cmd」启动。
2. 首次使用时，在 Edge 按 **Ctrl+Shift+B** 显示收藏夹栏，把面板中的「片段取材抓链」拖到收藏夹栏。以后点击已保存的书签即可。
3. 在同一个 Edge 配置文件中登录网盘，打开自己有下载权限的影片。点击抓链书签，再点播放触发抓取。百度的播放页若只返回在线播放流，可在文件列表选中同一影片，点击网页版的「下载」再试。面板收到原文件入口后会检查来源。 [迅雷云盘](https://pan.xunlei.com/) · [百度网盘](https://pan.baidu.com/)
4. 确认保存位置，填写一段或多段时间，点击「开始顺序取材」。完成后从「顺序队列与记录」打开文件夹。

包内含 Node、FFmpeg 和 FFprobe。抓链使用 Edge 内的网盘登录状态。首次验证可先取 15–30 秒，确认影片来源正确、成品能从中文路径打开。

如果没有自动打开 Edge，可在 Edge 地址栏粘贴启动窗口显示的 `http://127.0.0.1:端口`。如需安装 Edge，可前往 [微软官方下载页](https://www.microsoft.com/edge/download)。也可在保存位置栏直接填写完整 Windows 路径，例如 `D:\\片段素材`。

这是面向 Windows x64 的便携预览包。发布前的构建和验证记录见同目录的 `BUILD-INFO.json`，请在 Windows 设备上分别验证 Edge 收藏夹拖拽、两个网盘的真实登录和短片取材。
