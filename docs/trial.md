# 使用说明

这篇是给第一次用的人看的。想看它怎么实现的，去 [README](../README.md)。

---

## 一、先确认你要做的是什么事

Shark Clip 处理的是**「一支片子里的一段」**：

- ✅ 我有整支片（本地文件 / 网盘里的原片），想取其中 30 秒
- ❌ 我想把某个网站的在线视频下载下来（这不在范围内）

---

## 二、安装

### macOS（Apple Silicon）

1. 从 [Releases](https://github.com/Lysander5249/shark-clip/releases) 下载 `Shark-<版本>-mac-arm64.zip`
2. 解压，把 `Shark-mac-arm64.app` 拖到「应用程序」
3. **首次打开被系统拦住是正常的**——安装包还没有 Apple 公证。三种解法任选：
   - 右键点 App → 「打开」→ 弹窗里再点「打开」
   - 「系统设置 → 隐私与安全性」→ 页面下方点「仍要打开」
   - 命令行：`xattr -dr com.apple.quarantine /Applications/Shark.app`

> Intel Mac 和 macOS 13.5 以下没有测试，不保证可用。

### Windows（x64）

1. 下载 `Shark-<版本>-windows-x64-Edge-*.zip`
2. **完整解压**（不要在压缩包里直接双击运行）
3. 运行 `Shark.exe` 或 `启动片段取材.cmd`
4. 弹出 SmartScreen 时：点「更多信息」→「仍要运行」

取材期间要保持那个终端窗口开着，关掉就停了。

### 从源码跑

需要 Node.js 22+ 和 PATH 里的 `ffmpeg` / `ffprobe`：

```bash
npm start
```

## 三、第一次用，建议这么走

**第 1 步：用示例视频验证本地出片**

面板上有「使用示例视频」。选一个保存文件夹，随便填个时间范围，点开始。
能出片，说明 FFmpeg 和写权限都正常。**先过这一关，再碰云盘。**

**第 2 步：选保存位置**

默认是「影片/片段取材」（Mac）或 `Videos/片段取材`（Windows）。
如果开了 OneDrive，系统可能把「视频」目录重定向了，**建议手动选一次**，确认能写入。

**第 3 步：填时间范围**

格式 `时:分:秒`，例如：

```
01:12:30 - 01:12:45
```

前后余量会把范围稍微放宽一点，方便你在剪辑软件里再微调。

**第 4 步：多段就排队**

一次可以加多个片段，按顺序做，做完一个自动下一个。

## 四、用云盘片源

### 走 CloudDrive2 / WebDAV（推荐，最稳）

1. 在本机装好 CloudDrive2，登录你自己的迅雷或百度网盘
2. 回到 Shark →「我的云盘」→ 连接 `http://127.0.0.1:<端口>` 的 WebDAV
3. 浏览目录，选视频，填时间，开始

这条路的原理是标准的 HTTP Range 读取，兼容性最好。

### 走浏览器抓链（快，但依赖页面结构）

1. 在「浏览器抓链」里打开安装页，把书签拖进 Chrome（Mac）或 Edge（Windows）的书签栏
2. 在同一个浏览器里登录迅雷或百度网盘
3. 在网盘里打开目标影片、让它开始读取
4. 点一下书签栏里那个书签
5. 回到 Shark 核对片源，再填时间

> 页面结构变了抓链就可能失效，这不是 bug，是这类方案的固有代价。

## 五、出片格式

| 格式 | 说明 |
|---|---|
| **MKV 主本** | 视频流原样复制，**不重新编码**，画质零损失 |
| **MP4 工作副本** | 保留原视频编码，音频转 AAC 双声道，方便导入剪辑软件 |

MP4 不一定能被所有版本的剪映导入——它保留的是原编码（比如 HEVC）。
能不能导入，取决于你的剪辑软件，不取决于这个工具。

**HDR / 杜比视界没有做色调映射**，HDR 素材在剪辑软件里可能偏灰，需要你自己调。

---

## 六、关于流量数字

界面上显示的「接收」是**本工具自己收到的字节数**。

它**不包含** CloudDrive2 或网盘上游的预取、缓存、下载流量。
所以这个数字只能说明「本工具读了多少」，不能推断「上游只读了这么多」。

---

## 七、数据存在哪

| 内容 | 位置 |
|---|---|
| 导出的片段 | 你选的素材目录 |
| 任务记录 / 续传数据 | 素材目录下的 `.clip-fetcher-state/` |
| 云盘密码 | **只在本机进程内存里**，不写盘 |

删掉 `.clip-fetcher-state/` 就等于清空历史和续传进度，不影响已导出的片段。

## 八、出问题了怎么办

1. 先看面板上的错误文字和终端输出
2. 到 [Issues](https://github.com/Lysander5249/shark-clip/issues) 搜一下有没有同样的问题
3. 没有就新开一个，按模板填——**贴日志，别贴影片文件，也别贴带签名的下载直链**
