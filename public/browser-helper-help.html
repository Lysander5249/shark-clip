浏览器助手首次安装

此入口处于测试阶段，支持 Chrome 和 Edge，使用你在官方迅雷或百度网盘的正常登录。首次安装仍需手动加载扩展，尚未上架扩展商店；这一步还不是最终的即装即用体验。

1. 加载助手

  1. 下载浏览器助手 ZIP，解压到你准备保留的文件夹。
  2. Chrome 地址栏打开 chrome://extensions；Edge 打开 edge://extensions。
  3. 打开「开发者模式」，点击「加载已解压的扩展程序」或「加载解压缩的扩展」，选择包含 manifest.json 的文件夹。
  4. 可在浏览器扩展菜单中固定「片段取材」助手，方便再次打开。

2. 连接本次工具会话

  1. 安装助手后，回到工具，切换至「浏览器直连·测试」，点击「在 Chrome 连接助手」或「在 Edge 连接助手」。
  2. 在打开的本机配对页点击「连接当前工具」。也可在原工具点击「复制配对地址」，打开浏览器助手，粘贴地址后点击连接。

安装助手后，这里会出现连接按钮；未出现可使用原工具的「复制配对地址」。

重新打开工具或重置配对后，需要重新连接。配对地址只用于你这次打开的本机工具，请留在自己的浏览器助手中使用。

3. 识别影片并取片

  1. 在浏览器正常登录 迅雷云盘或百度网盘，进入存放影片的目录。
  2. 先在助手中点击「开始识别当前网页」，再回网页选择影片、打开文件详情或进行正常文件操作。助手只观察页面产生的入口，不需要先播放影片；网页刷新或切换后需重新开始识别。若没有找到来源，请查看助手状态，暂时可以继续使用原有云盘入口。
  3. 回到工具，从收到的候选中选择影片。检查通过后填写起止时间、保存位置与下载方式，开始取片。

候选需要经过实际源文件检查，网页播放流或转码结果不能直接视为原文件。流式直连的实际速度、账号限制与兼容性仍需真实片段验证；当前队列按顺序处理，同一影片可连续提交多个时段。
